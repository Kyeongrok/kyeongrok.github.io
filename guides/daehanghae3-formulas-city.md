## 시설 한눈에

도시에 들어가면 그림에서 건물을 눌러 들어갑니다. 건물마다 할 수 있는 일은 이렇습니다.

| 시설 | 할 수 있는 일 |
|---|---|
| 항구 | 출항 · 보급 · 함대편성 · 선원편성(선원 모집 · 해고) · 마을정보 · 발표(모항) |
| 조선소 | 배 구입 · 특별주문 · 매각 · 수리 · 개조 |

| 여관 | 숙박 · 허드렛일 · 부하편성 |
| 시장 | 아이템 구입 · 매각 |
| 교역소 | 매매 · 회화 · 투자(모드) — 매매 계산식은 [교역 · 계약]({{ '/guides/daehanghae3-formulas-trade/' | relative_url }}) 쪽에 있습니다 |

| 성문 | 탐험을 떠난다 · 발표(항구 없는 모항) |

숙박 · 허드렛일 · 휴양 · 교육 · 수련처럼 **마을에서 날이 가는 일**은 모두 같은 규칙을 따릅니다.

- 하루마다 피로가 1 줄고 사기가 3 오릅니다.
- 30일 이상 지나면 후원자의 「삐짐」이 모두 풀립니다.

식에 나오는 「지력」 같은 능력치는 화면에 보이는 값보다 1 작은 속값입니다.

## 항구

### 보급

배에 선원이 1명 이상 있어야 할 수 있습니다.

```
단가 = max(1, 밑값 × 시세 / 100)
```

| 품목 | 밑값 | 무게(한 통) | 비고 |
|---|---|---|---|
| 식량 | 15 | 5 | |
| 물 | 10 | 10 | 동남아시아 · 동아시아 · 신대륙의 42개 도시는 0 닢 |
| 자재 | 25 | 5 | |
| 탄약 | 25 | 20 | 파는 도시에서만 |

```
화면의 남은 일수 = min(식량, 물) × 10 / 선원 수
실제 하루 소모   = max(1, 선원 수 × 5 / 6)       (한 통 = 10)
```

화면에 나오는 일수보다 실제로는 20% 쯤 더 오래 갑니다(원본 그대로). 「10일분」은 선원 수만큼의 통입니다. 덜어 낸 것은 돈을 돌려주지 않습니다.

### 발표

모항에서 아직 발표하지 않은 발견물을 알립니다. 계약 중인 목표는 후원자에게 보고해야 하므로 빠집니다. 항구가 없는 모항(파리 따위)은 성문에서 발표합니다.

```
오르는 명성 = max(10, 보수 / 70)
```

- 발표하면 피로가 0 이 되고 사기가 가득 찹니다.
- 유적 속 물건 · 인물 · 비보처럼 자리가 없는 것은 「아무도 상대해 주지 않았습니다!」가 나오고 명성이 오르지 않습니다.
- 후원자에게 보고하면 `보수 / 50` 이라 발표보다 후합니다.

## 시장과 여관

### 시장(아이템) 값

```
구입가 = 정가 × 시세 / 100
매각가 = 정가 × 시세 / 100     (1000 닢 이상이면 100 닢 단위로 내림)
```

예: 정가 12000 닢인 바스타드소드는 시세 130 인 도시에서 15600 닢입니다.

### 숙박비

여관 값은 **한 달 선불**이고 도시의 문화권으로 정해집니다. 묵으면 30일이 지납니다.

```
숙박비 = 문화권 기본값 × 시세 / 100     (최소 1 닢)
```

| 문화권 | 기본값 | 문화권 | 기본값 |
|---|---|---|---|
| 이베리아 | 150 | 중국 | 90 |
| 북유럽 | 120 | 중앙아시아 | 30 |
| 지중해 | 124 | 동남아시아 | 30 |
| 아프리카 | 90 | 일본 | 60 |
| 이슬람 | 15 | 아메리카 | 30 |
| 인도 | 60 | | |

묵으면 컨디션이 `30 + rand(30)`(30~59) 오릅니다. 모항 여관이면 `rand(100) <= 5` 일 때 체력 · 지력 · 무력 · 매력 · 운 가운데 하나가 1 오릅니다(알림은 없습니다).

묵으면 그 고장 말을 모를 때 배울 기회가 있습니다. 세 번에 한 번꼴로 기회가 오고, 그때 `rand(100) < 지력 + 1` 이면 그 말을 1 단계로 배웁니다.

### 허드렛일

소지금이 **100 닢 이하**일 때만 여관에 「허드렛일」이 나옵니다.

- 꼬박 1년(365일)이 지납니다.
- 품삯은 `1200 × 시세 / 100` 닢입니다.
- 컨디션이 `rand(10) + 10`(10~19) 오릅니다.
- 숙박처럼 말을 배울 기회가 있습니다.

### 술집에서 한턱내기

- 금화 `rand(50) + 50`(50~99) 닢을 냅니다(소지금보다 많이 내지는 않습니다).
- 명성이 `rand(100) + 100`(100~199) 오릅니다.
- 악명이 `rand(6)`(0~5) 오릅니다.

## 술집 사람들

### 부하 고용에 필요한 명성

```
필요 명성 = 그 사람 명성 × 100 / (max(0, 매력 - 69) + 100) + 1
```

매력이 70 을 넘으면 넘는 만큼 필요한 명성이 줄어듭니다. 명성이 넉넉하면 아래 선금을 부릅니다.

```
선금 = 그 사람의 기본 선금 × (10 - 웅변) / 3
```

부하는 넷까지이고, 부관 · 통역 자리는 주인공과 말이 3 단계로 통하는 사람만 앉힐 수 있습니다.

### 여급과의 궁합

여급마다 숨은 「운명 번호」가 있고, 주인공 얼굴 번호와 **같거나 1 차이**면 궁합이 맞습니다. 주인공 얼굴 번호는 36살부터 나이 든 얼굴로 바뀌며 16 이 더해지므로, 나이에 따라 궁합이 맞는 여급이 달라집니다.

| 처음 말을 걸 때 | 친밀도 |
|---|---|
| 궁합이 맞음 | +50 |
| 궁합이 안 맞음 | +3 |
| 말이 통하지 않는 고장 | +20 |

친밀도는 0~100 입니다. 선물에 대한 반응은 친밀도 30 · 50 · 70 · 90 을 경계로 다섯 가지로 갈립니다.

리메이크에서 정한 값(원본 위치를 아직 못 찾은 것):

| 것 | 값 |
|---|---|
| 이야기할 때 오르는 친밀도 | 궁합이 맞으면 4, 아니면 2 |
| 선물로 오르는 친밀도 | 매각값 / 1000 (1~20) |
| 청혼이 받아들여지는 친밀도 | 100 |

## 선원과 배

### 선원 모집

```
한 사람 값 = max(10, (10000 - 명성) / 400)
```

명성이 높을수록 쌉니다. 명성 0 이면 25 닢, 1700 이면 20 닢, 6000 이 넘으면 바닥값인 10 닢입니다. 해고할 때 돈은 돌려받지 못합니다.

선원 월급은 확인 중입니다.

### 최저 승원과 정원

```
정원 = 최저 승원 × 5
```

| 선체 | 최저 승원 | 정원 |
|---|---|---|
| 코구 | 10 | 50 |
| 카라벨 | 15 | 75 |
| 카락 | 20 | 100 |
| 다우 | 25 | 125 |
| 대형카라벨 | 30 | 150 |
| 대형카락 | 35 | 175 |
| 갤리온 | 40 | 200 |
| 중카락 | 45 | 225 |

함대 전체의 최저 승원 · 정원은 배마다의 값을 더한 것입니다. 개조로 최저 승원이 늘면 정원도 함께 늡니다.

### 배 사고팔기

| | 식 |
|---|---|
| 구입 | 선체값 × 시세 / 100 |
| 매각 | 선체값 × 60 / 100 × 시세 / 100 |

선체값은 코구 7000 · 카라벨 10000 · 대형카라벨 40000 · 카락 50000 · 다우 60000 · 대형카락 100000 · 중카락 180000 · 갤리온 250000 닢입니다(원본 선체표 기준이며, 조선소에 따라 팔지 않는 선체도 있습니다). 기함은 팔 수 없습니다.

### 수리비

```
수리비 = (26 + rand(4)) × 손상 합계 × 시세 / 100     (최소 1 닢)
손상   = (최대 내구 - 지금 내구) + (최대 추진력 - 지금 추진력)
```

고른 배의 손상을 다 더한 뒤 주사위는 한 번만 굴립니다. 손상 한 점에 26~29 닢꼴입니다. 리메이크는 지금 내구만 셉니다.

### 개조비

모두 **그 도시에서 매긴 선체값**(선체값 × 시세 / 100)을 나눈 값입니다.

| 개조 | 값 | 얻는 것 | 잃는 것 |
|---|---|---|---|
| 마스트 추가 | 선체값 / 5 | 돛 하나 | 적재용량 -25, 최저 승원 +2 |
| 돛종류 변경 | 선체값 / 20 | 삼각돛(역풍) ↔ 사각돛(순풍) | — |
| 돛 추가 | 선체값 / 20 | 추진력 +10 | 최대 내구 -(늘어난 추진력 / 2), 최저 승원 +1 |
| 용량증가 | 선체값 / 15 | 적재용량 +50 | 아래 참고 |
| 부력증가 | 선체값 / 15 | 적재중량 +50 | 아래 참고 |
| 보강 | 선체값 / 15 | 최대 내구 +10, 지금 내구를 가득 채움 | 아래 참고 |
| 포탑수 변경 | 늘린 포탑 1개당 200 닢 | 포탑 | 떼는 것은 공짜 |

각 항목은 선체마다 정해진 상한까지만 늘어나며, 상한에 막혀 덜 늘면 아래의 손실도 그만큼 줄어듭니다.

**용량증가** — 늘어난 적재용량을 `n` 이라 하면 `d = n × 10`

- 적재중량 +d/3, 최대 추진력 -d/100, 최대 내구 -d/100, 최저 승원 +1

**부력증가** — 용량증가와 같은 꼴에서 적재중량과 적재용량이 자리를 바꿉니다(적재용량이 +d/3). 최저 승원은 늘지 않습니다.

**보강** — 늘어난 최대 내구를 `n` 이라 하면

- 최대 추진력 -n/3, 적재중량 -(n × 50 / 3)

보강은 수리를 겸합니다. 지금 내구가 새 최대 내구까지 꽉 찹니다.

### 대포

| 대포 | 한 문 값 | 한 문 무게 |
|---|---|---|
| 세이커포 | 250 | 15 |
| 캘버린포 | 1600 | 20 |
| 페리에포 | 2100 | 25 |
| 카논포 | 2500 | 30 |

```
실을 수 있는 문수 = min(포탑 수, 쓸 수 있는 무게 / 대포 한 문 무게)
```

포탑을 줄이거나 대포 종류를 바꾸면, 넘치거나 바꿔 내리는 대포는 **값의 30%** 로 되사 줍니다.

## 교회 · 조합 — 수련

건물마다 가르치는 기능 · 언어가 정해져 있고, 가르칠 것이 있는 건물에만 「수련」이 있습니다. 교회 · 조합이 아니어도 학자 저택처럼 가르치는 곳이 있습니다.

### 수련을 받으려면

- 가르치는 사람과 **통하는 말이 하나는 있어야** 합니다. 그 마을 나라의 말이나 그 건물이 가르치는 언어 가운데 하나라도 1 단계 이상이면 됩니다. 아니면 「말이 통하지 않는 상대로부터 배울 수는 없습니다」가 나옵니다.
- 아래 **한도**에 걸리면 「더 이상 기능을 습득할 수 없습니다!」가 나옵니다.
- 한 번에 한 단계만 오르고, 3 단계(숙달)면 더 배울 수 없습니다.

### 값과 기간

| 건물 | 값(금화) | 기간: 0→1 / 1→2 / 2→3 |
|---|---|---|
| 교회 | (지금 단계 + 1) × 100 | 3 / 6 / 12 개월 |
| 조합 | (지금 단계 + 1) × 120 | 3 / 6 / 12 개월 |
| 그 밖(학자 저택 등) | (지금 단계 + 1) × 150 | 2 / 5 / 10 개월 |

```
실제 일수 = (200 - 지력) × 개월 × 30 / 100
컨디션   += 일수 / 10
```

예: 지력 80 인 제독이 교회에서 검술 1→2 를 배우면 값은 200 닢, 일수는 `120 × 6 × 30 / 100 = 216` 일입니다.

### 배울 수 있는 한도

기능과 언어는 따로 셉니다.

```
무게 = 단계마다 1단계 1점 · 2단계 3점 · 3단계 6점을 모두 더한 값
배울 수 있음 = 무게 < (지력 × 3 + 3) / 5
```

예: 지력 73 이면 한도가 44 라, 기능 무게가 44 가 되기 전까지 배울 수 있습니다. 지력이 높을수록 많이 배웁니다.

### 숙달하면 오르는 능력치

어떤 기능이든 **3 단계가 되는 순간** 능력치가 오릅니다. `rand(3)` 은 0~2 입니다.

| 기능 | 오르는 능력 |
|---|---|
| 항해술 · 운용술 | 체력 rand(3) · 매력 rand(3) |
| 검술 | 무력 rand(3) + 1 |
| 포술 · 사격술 · 조선기술 | 체력 rand(3) · 무력 rand(3) |
| 의학 | 체력 rand(3) + 1 |
| 웅변 | 매력 rand(3) + 1 |
| 측량 | 체력 rand(3) · 지력 rand(3) |
| 역사학 · 회계 | 지력 rand(3) · 매력 rand(3) |
| 신학 · 과학 | 운 rand(3) + 2 |
| 언어(어느 것이든) | 지력 rand(3) |

`+1` · `+2` 가 붙지 않은 것은 0 이 나와 하나도 안 오를 수 있습니다.

## 도서관 — 열람

그 해에 그 도시 서가에 꽂힌 책이 있어야 「열람」이 나옵니다. 책을 여는 데 돈도 시간도 들지 않습니다. 서가 모양은 4년마다 바뀝니다.

### 힌트를 얻는 조건

힌트는 **그 쪽을 펼쳐 볼 때** 하나씩 들어옵니다. 넘겨 보지 않은 쪽의 힌트는 들어오지 않습니다. 세 가지를 모두 채워야 합니다.

1. **먼저 찾아야 하는 발견물** — 힌트마다 먼저 발견해 두어야 하는 발견물이 있습니다(역사 항해자가 찾은 것도 칩니다). 예: 톨레도의 「카파도키아」는 산티아고 대성당을 먼저 봐야 읽힙니다.
2. **언어** — 책의 언어가 **3 단계**여야 합니다.
3. **기능** — 힌트마다 정해진 기능 단계가 필요합니다(없는 힌트도 있습니다).

언어와 기능은 제독과 함대에 태운 부하 가운데 **가장 잘하는 사람**의 값으로 봅니다.

## 가족

### 혼인

청혼하면 네 번에 한 번(`rand(4) == 0`) 연적이 나타나 일기토를 겁니다. 이기면 명성이 100 오르고 혼인하며, 지면 혼인은 없던 일이 됩니다.

### 아이

- 자택에서 「후손을 남긴다」는 아내가 있고 **컨디션이 100** 일 때만 할 수 있습니다.
- 한 번에 **25%**(`rand(8) < 2`) 확률로 아이가 생기고, 열 달 뒤에 태어납니다.
- 아이는 둘까지이고, 둘째는 첫째와 반대 성별입니다.

### 딸의 결혼

저금이 10000 닢 이상이고 15살 이상인 딸이 있으면, 자택에 갈 때마다 **20%**(`rand(5) == 0`) 확률로 딸이 결혼 이야기를 꺼냅니다. 반대해도 결국 허락하게 되고 준비금 **10000 닢**이 나갑니다.

### 교육

- 10살 이상인 **맏아들**만 가르칠 수 있습니다. 딸은 가르칠 수 없습니다.
- 계약 중에는 교육할 수 없습니다.
- 주인공이 아들보다 **높은** 기능 · 언어만 가르칠 수 있습니다. 없으면 「더 이상 가르칠 것이 없습니다!」가 나옵니다.
- 한 번에 한 단계씩 오릅니다.

```
일수   = (120 - (아들 지력 + 1)) / 10 × 다음 단계 × 30
컨디션 += 일수 / 10          (주인공)
```

예: 지력 59 인 아들에게 1→2 단계를 가르치면 `60 / 10 × 2 × 30 = 360` 일이 걸립니다.

아들이 배울 수 있는 한도는 수련과 같은 셈이고 아들의 지력으로 봅니다.

```
무게 = 단계마다 1단계 1점 · 2단계 3점 · 3단계 6점을 모두 더한 값
배울 수 있음 = 무게 < (아들 지력 × 3 + 3) / 5
```

**능력치가 오르는 것은 주인공이 그 기능을 3 단계(숙달)로 가지고 있을 때뿐입니다.** 그때 수련의 「숙달하면 오르는 능력치」 표대로 아들의 능력치가 오릅니다. 주인공이 2 단계인 기능을 가르치면 아들의 기능 단계만 오르고 능력치는 오르지 않습니다. 원본은 이때 주인공의 능력치가 올랐는데, 리메이크는 아들의 능력치가 오르게 바꿨습니다.

### 세대교체

18살 이상인 아들에게 뒤를 잇게 할 수 있습니다(계약 중에는 불가). 물려받는 것은 이렇습니다.

|---|---|

## 적대 도시

적대 도시 성문 앞에서는 「공격한다 · 잠입한다 · 교섭한다 · 떠난다」를 고릅니다.

### 교섭

```
성공 = 웅변 × 33 + 매력 + 1  >=  rand(200)
```

성공 확률은 대략 `(웅변 × 33 + 매력 + 2) / 200` 입니다(최대 100%).

성공하면 문지기에게 돈을 건넵니다.

```
건네는 돈 = min(소지금, rand(500) + (5 - 웅변) × 100)
```

- 웅변이 높을수록 잘 되고 돈도 덜 듭니다. 웅변 3 이면 성공 문턱이 100 을 넘고, 돈은 200~699 닢입니다.
- 실패하면 그 방문 동안은 교섭을 다시 고를 수 없습니다. 물러났다가 다시 오면 다시 할 수 있습니다.

예: 웅변 2, 매력 50 이면 `66 + 50 + 1 = 117` 이라 성공률은 약 59%, 건네는 돈은 300~799 닢입니다.

### 잠입

```
성공 = 말 × 33 + 터번 + (운 + 1) / 2  >=  rand(250)
```

| 변수 | 뜻 |
|---|---|
| 말 | 그 도시가 쓰는 말을 아는 단계(0~3)입니다. |
| 터번 | 터번을 가지고 있으면 100, 없으면 0 입니다. |
| 운 | 주인공의 운입니다. |

잠입은 성공하든 실패하든 한 번뿐입니다. 들키면 달아나기를 굴립니다.

```
달아남 = rand(90) <= 체력 + 1
```

예: 말 2, 터번 없음, 운 50 이면 `66 + 25 = 91` 이라 잠입 성공률은 약 37% 입니다. 터번이 있으면 약 77% 로 오릅니다.

### 재판

달아나지 못하면 재판을 받습니다. 감옥은 없고 결과는 셋 가운데 하나입니다.

```
사형 = rand(2000) + 1000  <=  max(0, 악명 - 운 - 1)
```

사형을 피하면 다시 굴립니다.

```
추방 = rand(100) < 운 + 1        → 목숨만 건지고 쫓겨남
아니면 벌금형                     → 소지금을 전부 빼앗김
```

- 악명이 1000 미만이면 사형은 일어나지 않습니다. 악명이 높을수록, 운이 낮을수록 위험합니다.
- 사형이면 그대로 게임이 끝납니다.
