**읽기 전에**

- `rand(n)` 은 0 부터 n-1 까지 고르게 나오는 주사위입니다. `rand(200)` 이면 0~199 가운데 하나입니다.

## 교역소

### 교역품 값

교역소에서 **팔 때 받는 값**을 먼저 셈하고, **살 때 내는 값**은 거기에 3/2 를 곱합니다.

```
매각가 = 기준가 × 시세 / 100          (1 닢 밑으로는 내려가지 않음)
매각가 = 도시 상태 보정(매각가)
구입가 = 매각가 × 3 / 2
```

| 변수 | 뜻 |
|---|---|
| 기준가 | 교역품마다, 지역마다 정해진 값입니다. 그 도시 특산품이면 도시가 정한 특산 기준가를 씁니다. |
| 시세 | 그 도시의 시세(1~250)입니다. |
| 도시 상태 보정 | 전염병 · 기근 · 전쟁 같은 도시 상태에 따라 값이 바뀝니다(아래 표). |

- **금 · 은**은 시세를 곱하지 않습니다. 어느 도시에서나 기준가 그대로입니다.
- **향신료와 커피 · 담배 · 카카오 · 차**는 시세를 곱하기 전에 기준가가 따로 움직입니다(아래 「발견에 따라 움직이는 교역품」).
- **썩은 짐**은 0 닢에 팔립니다. 덜 썩었다고 값이 깎이지는 않습니다.

예: 시세가 130 인 리스본에서 기준가 155 인 대포는 `155 × 130 / 100 = 201` 닢에 팔리고, `201 × 3 / 2 = 301` 닢에 삽니다.

### 도시 상태가 값을 바꾸는 폭

도시 상태는 역사 사건이나 전염병 걸린 함대가 들어올 때 바뀌며, 저절로 풀리지는 않습니다.

| 상태 | 대상 | 값 |
|---|---|---|
| 전염병 | 약재 | ×2 |
| 기근 · 대기근 | 식료품 | ×1.5 |
| 풍작 | 식료품 / 기호품 | ×0.7 / ×1.3 |
| 대풍작 | 식료품 / 기호품 | ×0.5 / ×1.5 |
| 대한파 | 직물 | +30 닢 |
| 혹서 | 향신료 | ×1.3 |
| 노동력부족 | 노예 | ×1.5 |
| 전쟁 | 무기 · 광석 · 말 | ×1.5 |
| 축제 | 주류 | ×1.5 |
| 호경기 | 공예품 · 미술품 계열 · 견직물 | ×1.3 |
| 불경기 | 위와 같음 | ×0.7 |
| 대조선 | 목재 | ×1.5 |

호경기 · 불경기에 해당하는 교역품 분류의 정확한 이름은 확인 중입니다.

### 발견에 따라 움직이는 교역품

향신료는 「인도」와 「향료제도」를, 커피 · 담배 · 카카오 · 차는 같은 이름의 발견물을 **보고하거나 발표한 해**부터 지난 햇수(y)로 기준가가 바뀝니다. 아무도 보고하지 않았으면 「모름」입니다.

| 어디서 | 조건 | 기준가 배율 |
|---|---|---|
| 유럽(이베리아 · 북유럽 · 지중해) 향신료 | 향료제도를 앎 | max(70 - y, 40)% |
| 〃 | 인도만 앎 | max(95 - y, 75)% |
| 이슬람 · 인도 향신료 | 향료제도를 앎 | min(130 + y, 150)% |
| 〃 | 인도만 앎 | min(105 + y, 125)% |
| 동남아시아 향신료 | 향료제도를 앎 | min(5y + 15, 200)% |
| 〃 | 모름 | 10% |
| 유럽의 커피 · 담배 · 카카오 · 차 | 앎 | min(3y + 30, 200)% |
| 〃 | 모름 | 30% |

표에 없는 조합은 기준가 그대로입니다. 곧 향신료는 항로가 열릴수록 유럽에서는 싸지고 산지 쪽에서는 비싸지며, 신대륙 기호품은 유럽에 알려진 지 오래될수록 비싸집니다.

### 시세의 움직임

**거래할 때** — 한 번 거래가 성립하면 오간 돈만큼 그 도시 시세가 움직입니다. 사면 오르고 팔면 내립니다.

```
시세 변화 = (산 돈 - 판 돈) / (200 × (5 × 규모 + 10))
```

- 한 번에 -50 ~ +50 까지만 움직이고, 시세는 1~250 사이에 머뭅니다.
- 규모는 도시 크기(0~7)입니다. 큰 도시일수록 시세가 덜 흔들립니다.

예: 규모 4 인 리스본에서 6만 닢어치를 사면 `60000 / (200 × 30) = 10` 이 올라 시세가 10 오릅니다.

**매달 1일** — 모든 도시의 시세가 조금씩 흔들리며 목표값 쪽으로 돌아갑니다.

```
시세 = 시세 + rand(9) - 4          (1~250 으로 자름)
시세가 목표보다 높으면 rand(4) + 1 만큼 내리고, 낮으면 그만큼 올림
```

| 목표값 | 조건 |
|---|---|
| 100 | 처음 |
| 130 | 누군가 아즈텍왕국을 발견한 뒤 |
| 170 | 잉카제국까지 발견한 뒤 |

### 공급량(재고)

교역소 재고는 **매달 1일에 상한까지 다시 찹니다.** 플레이어가 판 물건은 재고에 더해지지 않습니다.

| 도시 규모 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|---|
| 재고 상한 | 20 | 50 | 100 | 200 | 350 | 500 | 700 | 1000 |

일반 교역품은 도시 규모로, 특산품은 도시마다 정해진 특산품 등급으로 상한을 고릅니다. 리메이크에서는 특산품도 등급과 규모 가운데 큰 쪽을 씁니다.

### 흥정(값 깎기)

교역소에서 살 것을 고르고 「결정」을 누르면 「결정 / 값을 깎는다 / 돌아간다」를 묻습니다.

**흥정 메뉴가 뜨는 조건** — 그 도시 나라말을 주인공 · 부관 · 통역 가운데 누군가 **2 단계 이상** 할 줄 알아야 합니다.

**성공률** — 주인공과 부관 가운데 높은 **회계** 단계로 정해집니다.

| 회계 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 성공률 | 40% | 70% | 85% | 95% |

**깎이는 폭** — 한 번 성공할 때마다 총액이 95% 가 됩니다. 곱해지므로 두 번이면 약 90%, 세 번이면 약 86% 입니다.

```
새 총액 = 총액 × 95 / 100      (최소 1 닢)
```

**언제 끝나는가** — 성공 · 실패를 가리지 않고 시도 횟수로 셉니다.

- 첫 시도에서 실패하면 상인이 거절할 뿐 흥정은 이어집니다.
- **두 번째 시도부터는 실패하는 순간 거래가 깨집니다.**
- 세 번을 모두 성공하면 더 묻지 않고 그 값에 바로 거래가 성립합니다.

**대가**

- 「값을 깎는다」를 누를 때마다 악명이 1 오르고, 세 번째 성공으로 거래가 성립하면 3 더 오릅니다.
- 거래가 깨지면 상인이 그 교역소 물건을 거둬 갑니다.

| 상황 | 줄어드는 공급량 |
|---|---|
| 두 번째 시도에서 깨짐 | 줄마다 50% |
| 세 번째 시도에서 깨짐 | 줄마다 100% — 다 사라짐 |
| 흥정만 하고 사지 않고 나감 | 줄마다 10% |

예: 회계 1 로 첫 시도에 성공(70%)해 값이 95% 가 된 뒤 한 번 더 깎으려다 실패하면, 「이쪽은 바쁘다네. 살 마음이 없으면 돌아가게.」와 함께 거래가 깨지고 교역소 공급량이 절반으로 줄어듭니다. 세 번 모두 성공할 확률은 회계 3 이어도 약 86%, 회계 0 이면 약 6% 입니다.

## 시장과 여관

### 시장(아이템) 값

```
구입가 = 정가 × 시세 / 100
매각가 = 정가 × 시세 / 100     (1000 닢 이상이면 100 닢 단위로 내림)
```

예: 정가 12000 닢인 바스타드소드는 시세 130 인 도시에서 15600 닢입니다.

### 숙박비

여관 값은 **한 달 선불**이고 도시의 문화권으로 정해집니다. 묵으면 30일이 지납니다.

```
숙박비 = 문화권 기본값 × 시세 / 100     (최소 1 닢)
```

| 문화권 | 기본값 | 문화권 | 기본값 |
|---|---|---|---|
| 이베리아 | 150 | 중국 | 90 |
| 북유럽 | 120 | 중앙아시아 | 30 |
| 지중해 | 124 | 동남아시아 | 30 |
| 아프리카 | 90 | 일본 | 60 |
| 이슬람 | 15 | 아메리카 | 30 |
| 인도 | 60 | | |

묵으면 그 고장 말을 모를 때 배울 기회가 있습니다. 세 번에 한 번꼴로 기회가 오고, 그때 `rand(100) < 지력 + 1` 이면 그 말을 1 단계로 배웁니다.

### 허드렛일

소지금이 **100 닢 이하**일 때만 여관에 「허드렛일」이 나옵니다.

- 꼬박 1년(365일)이 지납니다.
- 품삯은 `1200 × 시세 / 100` 닢입니다.
- 컨디션이 `rand(10) + 10`(10~19) 오릅니다.
- 숙박처럼 말을 배울 기회가 있습니다.

### 술집에서 한턱내기

- 금화 `rand(50) + 50`(50~99) 닢을 냅니다(소지금보다 많이 내지는 않습니다).
- 명성이 `rand(100) + 100`(100~199) 오릅니다.
- 악명이 `rand(6)`(0~5) 오릅니다.

## 선원과 배

### 선원 모집

```
한 사람 값 = max(10, (10000 - 명성) / 400)
```

명성이 높을수록 쌉니다. 명성 0 이면 25 닢, 1700 이면 20 닢, 6000 이 넘으면 바닥값인 10 닢입니다. 해고할 때 돈은 돌려받지 못합니다.

선원 월급은 확인 중입니다.

### 최저 승원과 정원

```
정원 = 최저 승원 × 5
```

| 선체 | 최저 승원 | 정원 |
|---|---|---|
| 코구 | 10 | 50 |
| 카라벨 | 15 | 75 |
| 카락 | 20 | 100 |
| 다우 | 25 | 125 |
| 대형카라벨 | 30 | 150 |
| 대형카락 | 35 | 175 |
| 갤리온 | 40 | 200 |
| 중카락 | 45 | 225 |

함대 전체의 최저 승원 · 정원은 배마다의 값을 더한 것입니다. 개조로 최저 승원이 늘면 정원도 함께 늡니다.

### 배 사고팔기

| | 식 |
|---|---|
| 구입 | 선체값 × 시세 / 100 |
| 매각 | 선체값 × 60 / 100 × 시세 / 100 |

선체값은 코구 7000 · 카라벨 10000 · 대형카라벨 40000 · 카락 50000 · 다우 60000 · 대형카락 100000 · 중카락 180000 · 갤리온 250000 닢입니다(원본 선체표 기준이며, 조선소에 따라 팔지 않는 선체도 있습니다). 기함은 팔 수 없습니다.

### 수리비

```
수리비 = (26 + rand(4)) × 손상 합계 × 시세 / 100     (최소 1 닢)
손상   = (최대 내구 - 지금 내구) + (최대 추진력 - 지금 추진력)
```

고른 배의 손상을 다 더한 뒤 주사위는 한 번만 굴립니다. 손상 한 점에 26~29 닢꼴입니다. 리메이크는 지금 내구만 셉니다.

### 개조비

모두 **그 도시에서 매긴 선체값**(선체값 × 시세 / 100)을 나눈 값입니다.

| 개조 | 값 | 얻는 것 | 잃는 것 |
|---|---|---|---|
| 마스트 추가 | 선체값 / 5 | 돛 하나 | 적재용량 -25, 최저 승원 +2 |
| 돛종류 변경 | 선체값 / 20 | 삼각돛(역풍) ↔ 사각돛(순풍) | — |
| 돛 추가 | 선체값 / 20 | 추진력 +10 | 최대 내구 -(늘어난 추진력 / 2), 최저 승원 +1 |
| 용량증가 | 선체값 / 15 | 적재용량 +50 | 아래 참고 |
| 부력증가 | 선체값 / 15 | 적재중량 +50 | 아래 참고 |
| 보강 | 선체값 / 15 | 최대 내구 +10, 지금 내구를 가득 채움 | 아래 참고 |
| 포탑수 변경 | 늘린 포탑 1개당 200 닢 | 포탑 | 떼는 것은 공짜 |

각 항목은 선체마다 정해진 상한까지만 늘어나며, 상한에 막혀 덜 늘면 아래의 손실도 그만큼 줄어듭니다.

**용량증가** — 늘어난 적재용량을 `n` 이라 하면 `d = n × 10`

- 적재중량 +d/3, 최대 추진력 -d/100, 최대 내구 -d/100, 최저 승원 +1

**부력증가** — 용량증가와 같은 꼴에서 적재중량과 적재용량이 자리를 바꿉니다(적재용량이 +d/3). 최저 승원은 늘지 않습니다.

**보강** — 늘어난 최대 내구를 `n` 이라 하면

- 최대 추진력 -n/3, 적재중량 -(n × 50 / 3)

보강은 수리를 겸합니다. 지금 내구가 새 최대 내구까지 꽉 찹니다.

### 대포

| 대포 | 한 문 값 | 한 문 무게 |
|---|---|---|
| 세이커포 | 250 | 15 |
| 캘버린포 | 1600 | 20 |
| 페리에포 | 2100 | 25 |
| 카논포 | 2500 | 30 |

```
실을 수 있는 문수 = min(포탑 수, 쓸 수 있는 무게 / 대포 한 문 무게)
```

포탑을 줄이거나 대포 종류를 바꾸면, 넘치거나 바꿔 내리는 대포는 **값의 30%** 로 되사 줍니다.

## 후원자와 계약

### 설득이 받아들여지는가

1. **이야기 크기** — 힌트 등급이 `명성 / 2000 + 1` 이하면 괜찮고, `+ 2` 까지는 한 번 더 물어보며, 그보다 크면 아예 받지 않습니다.
2. **좋아하는 갈래** — 후원자가 좋아하는 갈래의 힌트면 두말없이 원조합니다.
3. **말솜씨** — 아니면 아래 굴림을 넘으면 마지못해 원조합니다.

   ```
   안목 + (웅변 × 33 + 매력 + 1) / 2  >=  rand(200)
   ```

4. 그것도 안 되면 다시 `안목 + ((웅변 × 5 + 5) × 5 + 매력 + 1) / 2 > rand(150)` 을 굴려, 넘으면 다른 이야기를 고를 수 있고 못 넘으면 기분이 상해 한동안 만나 주지 않습니다.
5. **안목 관문** — 마지막으로 후원자의 `안목 / 20 + 2`(등급 5 는 `+ 1`)가 힌트 등급 이상이어야 합니다. 등급 3 은 안목 20, 4 는 40, 5 는 80 이 필요합니다. 여기서 물려도 기분은 상하지 않습니다.

안목은 후원자의 능력치입니다.

### 계약금

```
계약금 = max(힌트 자금, 5000) × (친밀 기준 / 2 + 50) / 100 × 열의 / 100
```

| 변수 | 뜻 |
|---|---|
| 힌트 자금 | 힌트마다 정해진 값입니다. 5000 보다 작으면 5000 으로 칩니다. |
| 친밀 기준 | 후원자마다 정해진 값입니다. 후원자 정보 창의 「친밀도」(0 에서 시작해 보고로 오르는 값)와는 다른 값입니다. |
| 열의 | 좋아하는 갈래라 두말없이 받으면 125, 마지못해 받으면 75 입니다. |

- 계약금은 최소 20 닢이고 10 닢 단위로 내립니다.
- 후원자의 자금보다 많이 줄 수는 없습니다.

**받는 방식** — 계약금은 정확히 반으로 나뉩니다.

```
선금 = 계약금 / 2       (계약할 때 바로 받음)
미불 = 계약금 / 2       (보고할 때 사례의 밑값이 됨)
기한 = 힌트마다 정해진 햇수 + 1 년
```

### 보고 사례금

계약한 목표를 찾아 후원자에게 보고하면 미불금에 비율을 곱해 받습니다.

```
기한 안 : 사례 = 미불 × (120 + rand(30)) / 100      → 미불의 120~149%
늦음    : 사례 = 미불 × (90 - rand(20)) / 100       → 미불의 71~90%
```

사례는 100 닢 단위로 내립니다(100 닢 이하면 그대로).

예: 계약금 124300 닢이면 선금 62150 닢을 먼저 받고, 기한 안에 보고하면 62150 × 120~149% = 약 74500~92600 닢을 더 받습니다.

다른 항해자가 먼저 발표해 버린 목표라면 기한 안이어도 `계약금 / 4` 만 받고, 기한을 넘겼으면 한 푼도 받지 못합니다.

### 보고 · 발표로 오르는 명성

여기서 「가치」는 발견물마다 정해진 값입니다. 세계일주항로가 300000 으로 가장 큽니다.

| 방법 | 기한 안 | 늦음 |
|---|---|---|
| 후원자에게 보고 | max(10, 가치 / 50) | max(10, 가치 / 50) / 2 |
| 후원자에게 보고 — 세계일주항로 | max(10, 가치 / 50) | max(10, 가치 / 60) |
| 항구에서 발표(계약 없이 찾은 것) | max(10, 가치 / 70) | — |
| 이미 남이 보고한 발견물 | 0 | 0 |

- 계약으로 맡은 발견물은 항구에서 발표할 수 없고 후원자에게만 보고할 수 있습니다.
- 보고하거나 발표하면 함대 피로도가 0, 규율이 100 이 됩니다.
- 서적 · 유물 같은 발견물이 준 물건은 보고해도 빼앗기지 않습니다.

**후원자 친밀도** — 보고하면 후원자 친밀도(0~100)도 오릅니다.

| | 기한 안 | 늦음 |
|---|---|---|
| 새 발견물 | max(1, 가치 / 10000) + 덤 | (max(2, 가치 / 10000) + 덤) / 2 |
| 이미 알려진 발견물 | 그대로 | -(rand(5) + 5) |

덤은 그 후원자가 좋아하는 갈래의 발견물일 때 `rand(10)`, 아니면 0 입니다.

### 계약중단과 위약금

기한이 지나도 저절로 아무 일도 일어나지 않습니다. 후원자를 다시 찾아가 「계약중단」을 고를 때 따집니다.

```
위약금 = 계약금 / 2     (곧 받은 선금)
```

위약금을 낼지는 아래 굴림으로 정해집니다.

```
문턱 = min(97, 후원자 명성 / 100 + 주인공 쪽 값 + 1)
용서받음 = rand(기한 안이면 100, 넘겼으면 150) < 문턱
```

- 용서받으면 위약금을 내고 후원자 친밀도가 20 내려갑니다. 위약금을 못 내면 미움을 삽니다.
- 용서받지 못하면 후원자가 등을 돌립니다.
- 높은 신분의 후원자일수록 명성이 높아 너그럽습니다. 「주인공 쪽 값」이 무엇인지는 원본에서 확인 중이며, 리메이크는 주인공 명성 / 100 을 씁니다.

## 술집 사람들

### 부하 고용에 필요한 명성

```
필요 명성 = 그 사람 명성 × 100 / (max(0, 매력 - 69) + 100) + 1
```

매력이 70 을 넘으면 넘는 만큼 필요한 명성이 줄어듭니다. 명성이 넉넉하면 아래 선금을 부릅니다.

```
선금 = 그 사람의 기본 선금 × (10 - 웅변) / 3
```

부하는 넷까지이고, 부관 · 통역 자리는 주인공과 말이 3 단계로 통하는 사람만 앉힐 수 있습니다.

### 여급과의 궁합

여급마다 숨은 「운명 번호」가 있고, 주인공 얼굴 번호와 **같거나 1 차이**면 궁합이 맞습니다. 주인공 얼굴 번호는 36살부터 나이 든 얼굴로 바뀌며 16 이 더해지므로, 나이에 따라 궁합이 맞는 여급이 달라집니다.

| 처음 말을 걸 때 | 친밀도 |
|---|---|
| 궁합이 맞음 | +50 |
| 궁합이 안 맞음 | +3 |
| 말이 통하지 않는 고장 | +20 |

친밀도는 0~100 입니다. 선물에 대한 반응은 친밀도 30 · 50 · 70 · 90 을 경계로 다섯 가지로 갈립니다.

리메이크에서 정한 값(원본 위치를 아직 못 찾은 것):

| 것 | 값 |
|---|---|
| 이야기할 때 오르는 친밀도 | 궁합이 맞으면 4, 아니면 2 |
| 선물로 오르는 친밀도 | 매각값 / 1000 (1~20) |
| 청혼이 받아들여지는 친밀도 | 100 |

## 가족

### 혼인

청혼하면 네 번에 한 번(`rand(4) == 0`) 연적이 나타나 일기토를 겁니다. 이기면 명성이 100 오르고 혼인하며, 지면 혼인은 없던 일이 됩니다.

### 아이

- 자택에서 「후손을 남긴다」는 아내가 있고 **컨디션이 100** 일 때만 할 수 있습니다.
- 한 번에 **25%**(`rand(8) < 2`) 확률로 아이가 생기고, 열 달 뒤에 태어납니다.
- 아이는 둘까지이고, 둘째는 첫째와 반대 성별입니다.

### 딸의 결혼

저금이 10000 닢 이상이고 15살 이상인 딸이 있으면, 자택에 갈 때마다 **20%**(`rand(5) == 0`) 확률로 딸이 결혼 이야기를 꺼냅니다. 반대해도 결국 허락하게 되고 준비금 **10000 닢**이 나갑니다.

### 교육

- 10살 이상인 **아들**만 가르칠 수 있습니다. 딸은 가르칠 수 없습니다.
- 주인공이 아들보다 높은 기능만 가르칠 수 있습니다.
- 계약 중에는 교육할 수 없습니다.

### 세대교체

18살 이상인 아들에게 뒤를 잇게 할 수 있습니다(계약 중에는 불가). 물려받는 것은 이렇습니다.

| 것 | 물려받는 값 |
|---|---|
| 금화 | 금화 × 2 / 3 |
| 저금 | 저금 × 4 / 5 |
| 명성 | 3000 미만이면 0, 6000 미만이면 명성 / 5, 그 이상이면 명성 / 5 + 1000 |
| 악명 | 2000 미만이면 0, 5000 미만이면 악명 / 8, 그 이상이면 악명 / 8 + 1000 |

예: 명성 7000 이면 아들은 `7000 / 5 + 1000 = 2400` 으로 시작합니다.

## 적대 도시

적대 도시 성문 앞에서는 「공격한다 · 잠입한다 · 교섭한다 · 떠난다」를 고릅니다.

### 교섭

```
성공 = 웅변 × 33 + 매력 + 1  >=  rand(200)
```

성공 확률은 대략 `(웅변 × 33 + 매력 + 2) / 200` 입니다(최대 100%).

성공하면 문지기에게 돈을 건넵니다.

```
건네는 돈 = min(소지금, rand(500) + (5 - 웅변) × 100)
```

- 웅변이 높을수록 잘 되고 돈도 덜 듭니다. 웅변 3 이면 성공 문턱이 100 을 넘고, 돈은 200~699 닢입니다.
- 실패하면 그 방문 동안은 교섭을 다시 고를 수 없습니다. 물러났다가 다시 오면 다시 할 수 있습니다.

예: 웅변 2, 매력 50 이면 `66 + 50 + 1 = 117` 이라 성공률은 약 59%, 건네는 돈은 300~799 닢입니다.

### 잠입

```
성공 = 말 × 33 + 터번 + (운 + 1) / 2  >=  rand(250)
```

| 변수 | 뜻 |
|---|---|
| 말 | 그 도시가 쓰는 말을 아는 단계(0~3)입니다. |
| 터번 | 터번을 가지고 있으면 100, 없으면 0 입니다. |
| 운 | 주인공의 운입니다. |

잠입은 성공하든 실패하든 한 번뿐입니다. 들키면 달아나기를 굴립니다.

```
달아남 = rand(90) <= 체력 + 1
```

예: 말 2, 터번 없음, 운 50 이면 `66 + 25 = 91` 이라 잠입 성공률은 약 37% 입니다. 터번이 있으면 약 77% 로 오릅니다.

### 재판

달아나지 못하면 재판을 받습니다. 감옥은 없고 결과는 셋 가운데 하나입니다.

```
사형 = rand(2000) + 1000  <=  max(0, 악명 - 운 - 1)
```

사형을 피하면 다시 굴립니다.

```
추방 = rand(100) < 운 + 1        → 목숨만 건지고 쫓겨남
아니면 벌금형                     → 소지금을 전부 빼앗김
```

- 악명이 1000 미만이면 사형은 일어나지 않습니다. 악명이 높을수록, 운이 낮을수록 위험합니다.
- 사형이면 그대로 게임이 끝납니다.
