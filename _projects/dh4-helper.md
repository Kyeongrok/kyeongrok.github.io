## 소개

**대항해시대4 리마스터**를 더 편하게 즐기도록 도와주는 Windows 런처입니다.
해상도와 조작 키를 바꾸고, 초상화나 지도 같은 게임 데이터를 직접 고칠 수 있습니다.

<img class="screenshot" src="{{ '/assets/images/dh4-helper.jpg' | relative_url }}" alt="대항해시대4 헬퍼 실행 화면">

## 기능

- **게임 설정** — 게임 폴더 지정, 해상도 변경(고해상도 화면 자동 대응), 전체 화면, 언어 선택
- **고성능 GPU 적용** — 그래픽카드가 있으면 게임이 그래픽카드를 쓰도록 설정
- **키 매핑** — 돛 조타, 배 선회, 지도(F1), 기능 키(F2–F5), 넘패드, 숫자 키를 원하는 키로 변경
- **이미지 교체** — 초상화, 컷신, 도시 배경, 건물 이미지를 보고 교체 (원본은 자동 백업되고 되돌릴 수 있음)
- **지도 편집기** — 실제 게임 타일로 세계 지도를 보여주고 직접 편집
- **세이브 편집** — 주인공별 자금 수정
- **게임 실행** — 런처에서 바로 게임 실행

키 매핑은 스팀판에서는 지원하지 않습니다.

## 설치 방법

- **설치판 (권장)** — `Dh4Launcher-win-Setup.exe`를 실행하면 설치됩니다. 이후 새 버전이 나오면 자동으로 업데이트됩니다.
- **포터블** — `Dh4Launcher-win-Portable.zip`의 압축을 풀고 실행합니다.

처음 실행하면 대항해시대4 리마스터가 설치된 게임 폴더를 지정해 주세요.

## 필요 환경

- Windows 10 / 11 (64비트)
- 대항해시대4 리마스터
